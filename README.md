# Comments — тестовое задание (dZENcode)

Django-приложение для древовидных комментариев с вложениями,
CAPTCHA, сортировкой, пагинацией и live-обновлением через WebSocket.

## О frontend-части

Так как я backend-разработчик:
основной рендеринг — на серверных Django-шаблонах, без полноценного
SPA на Vue/React/Angular.

Там, где ТЗ прямо требует JS-интерактивности без перезагрузки страницы
(панель HTML-тегов и предпросмотр комментария), добавлен точечный слой
на **Vue 3** (CDN, без сборки/npm) — `static/js/comment-editor.js` +
`templates/comments/_text_editor.html`. Остальное (сортировка, пагинация,
отправка формы, вывод дерева комментариев) осталось на стороне Django —
осознанно, чтобы не переусложнять то, что и так работает.

Такое разделение позволило направить основное время на бизнес-логику,
безопасность (XSS/SQLi), валидацию, тесты и архитектуру — то есть на то,
что было заявлено как приоритет тестового задания.

## Функционал

- Добавление комментария: User Name, E-mail, Home page, Text, CAPTCHA, файл
- Ответы на комментарии (неограниченная вложенность)
- Разрешённые HTML-теги в тексте: `<a href="" title="">`, `<code>`, `<i>`, `<strong>`
- Защита от XSS и SQL-инъекций
- Прикрепление изображения (JPG/GIF/PNG, авто-уменьшение до 320×240) или TXT (до 100 КБ)
- Таблица корневых комментариев с сортировкой по User Name / E-mail / дате
- Пагинация по 25 записей
- Уведомление о новых комментариях через WebSocket
- Панель HTML-тегов и живой предпросмотр комментария — на Vue 3 (CDN)
- Docker / docker-compose для полного окружения (Django + PostgreSQL)

## Стек

Django 6.1, Django Channels + Daphne (ASGI, WebSocket), PostgreSQL 16,
Pillow, django-simple-captcha, Vue 3 (CDN, точечно), Docker / docker-compose.

## Запуск с нуля

1. Скопировать `.env.example` в `.env` и заполнить значения (SECRET_KEY,
   пароль БД, ALLOWED_HOSTS).
2. `docker compose up --build`
3. Открыть `http://localhost:8000/`

Миграции и `collectstatic` выполняются автоматически при старте контейнера
(`entrypoint.sh`).

## Структура БД

Схема — в `schema.sql` (диалект MySQL, специально для импорта в
MySQL Workbench через File → Import → Reverse Engineer SQL Script).
Реальная СУБД проекта — PostgreSQL.

## Админка

`/admin/` — управление комментариями (`comments.Comment`).

## Известные ограничения

- **WebSocket / `CHANNEL_LAYERS`.** Используется `InMemoryChannelLayer` —
  группа `comments`, через которую рассылается уведомление о новом
  комментарии, хранится в памяти одного процесса. Это осознанное
  упрощение для тестового задания: при одном инстансе/воркере (как на
  бесплатном тарифе Render) всё работает корректно. Если приложение
  когда-либо будет запущено в нескольких процессах или на нескольких
  инстансах, уведомления перестанут доходить до клиентов, подключённых
  к другому процессу — для этого потребуется вынести `CHANNEL_LAYERS`
  на `channels_redis` (Redis pub/sub) как общее хранилище между
  процессами.
